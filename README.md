# Köşe · Boks Antrenörü

Evde boks antrenmanı için sesli antrenör: gölge boksu, sanal lapacı, rakip figür, kendi modların ve kombinasyonların, istatistik ve kamerayla gard takibi.

- Tamamen tarayıcıda çalışır; kamera görüntüsü cihazdan çıkmaz.
- Kurulum: Edge ya da Chrome ile aç → adres çubuğundaki "Uygulamayı yükle".
- 3B boksör modeli: three.js örneklerindeki Xbot (Mixamo). Vücut takibi: Google MediaPipe Pose Landmarker (lite).
